# RV32I SHA-256 Build

This builds the string-free implementation of the SHA256 c++ algorithm, and checks that it has no unresolved symbols.
In the spirit of automation, the shell and PowerShell scripts were generated by AI, but checked by a real human.

## Requirements

- WSL 2, Linux, or native Windows PowerShell
- A bare-metal RISC-V GCC toolchain containing `g++`, `nm`, and `size`
- An RV32I/ILP32 multilib in the cross-toolchain

Even though it's called `riscv64`, `-march=rv32i -mabi=ilp32` selects the
32-bit target used by PicoRV32.

## Toolchain install on Ubuntu or WSL

```bash
sudo apt update
sudo apt install gcc-riscv64-unknown-elf binutils-riscv64-unknown-elf
```

Check that the required RV32I multilib is available:

```bash
riscv64-unknown-elf-g++ -print-multi-lib | grep 'rv32i/ilp32'
```

## Toolchain install on native Windows
Note that this may require using npm, so in the far future, if npm continues to have security issues, like the countless times it's already had them, it may be better to use Linux. Up to you.

Install the xPack RISC-V Embedded GCC toolchain, then add its `bin` directory to
your user `PATH`. The xPack executables normally use the
`riscv-none-elf-*` prefix. See below for manual install, or run:

```powershell
npm install --location=global xpm@latest
xpm install @xpack-dev-tools/riscv-none-elf-gcc@latest --global --verbose
```

The global xpm installation prints the installed location. Add its
`.content\bin` directory to `PATH`, and if you want, verify that it's installed:

```powershell
riscv-none-elf-g++ --version
riscv-none-elf-g++ -print-multi-lib | Select-String 'rv32i/ilp32'
```

See the [xPack RISC-V GCC installation guide](https://xpack-dev-tools.github.io/riscv-none-elf-gcc-xpack/docs/install/)
for the manual ZIP installation and current package versions.

## Build on WSL or Linux

From this directory:

```bash
bash build_rv32i.sh
```

The Bash script defaults to the Ubuntu tool names. Other prefixes can be passed
through environment variables:

```bash
CXX=riscv-none-elf-g++ NM=riscv-none-elf-nm SIZE=riscv-none-elf-size bash build_rv32i.sh
```

## Build on native Windows

From this directory in PowerShell:

```powershell
.\build_rv32i.ps1
```

The script detects both common tool prefixes. You can override the prefix when
using another compatible distribution:

```powershell
$env:RISCV_TOOL_PREFIX = 'riscv-none-elf'
.\build_rv32i.ps1
```

## Manual compile on Ubuntu/WSL/Linux

Or, you can compile with:

```bash
riscv64-unknown-elf-g++ \
  -std=c++11 \
  -O2 \
  -Wall -Wextra -Werror \
  -march=rv32i \
  -mabi=ilp32 \
  -DSHA256_NO_STD_STRING \
  -ffreestanding \
  -fno-exceptions \
  -fno-rtti \
  -fno-threadsafe-statics \
  -fno-stack-protector \
  -c sha256.cpp \
  -o build/sha256_rv32i.o
```

It then checks the object with `riscv64-unknown-elf-nm -C -u`. Any unresolved
symbol makes the build fail. Output goes in the `build/` directory.

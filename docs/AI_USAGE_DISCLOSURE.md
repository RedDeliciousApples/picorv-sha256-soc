While I want this project to be as human as reaonably possible, I used some AI (specifically ChatGPT) to reduce development
time for the following tasks: boilerplate, module instantiations, documentation scaffolding, and debugging ideas.
All AI-generated material was treated as a draft, and most was rewritten by me. I decided on this approach because unfortunately,
there's precious little info about AXI-4 Lite on the internet outside of AMD's own documentation. So while AI was used to 
help me parse that documentation more efficiently, note that the AXI implementation, as well as all diagrams, architectural decisions,
and modules were my own ideas.
